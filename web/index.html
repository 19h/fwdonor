Drop firmware images to grow the zrax corpus. zrax checks each file in this tab first. Only images it recognizes are uploaded. The server checks them again, posts them to the zrax firmware group ↗ on Telegram with what zrax found.

Images, documents, archives of non-firmware, ROMs and memory dumps are skipped and never leave your browser. Each file can be up to 512 MiB. Images already in the collection are recognized by their SHA-256 and not uploaded again. Please only donate images you have the right to share.
